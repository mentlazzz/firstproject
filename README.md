# CAREA — web

- `index.html` — stránka
- `css/tokens.css` — design tokeny (primitive → semantic → component), písmo Jost
- `css/styles.css` — vzhled
- `js/main.js` — úvodní animace (GSAP)
- `img/hero.jpg` — hlavní fotka úvodu
