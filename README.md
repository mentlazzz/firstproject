# CAREA — web

Web CAREA — ruční automyčka a čištění interiérů, Kralupy nad Vltavou.
Živě: https://mentlazzz.github.io/firstproject/

- `index.html` — stránka (úvod s animací mytí, programy, mytí & Winter, konzervace, doplňky, odvoz, pro firmy, recenze, kontakt)
- `css/tokens.css` — design tokeny (primitive → semantic → component), písmo Jost
- `css/styles.css` — vzhled
- `js/main.js` — animace (GSAP + ScrollTrigger), formulář, menu
- `frames/lg`, `frames/sm` — snímky videa mytí auta (přehrávají se podle scrollu)
- `img/` — detailní záběry z videa
